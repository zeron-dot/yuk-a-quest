# 육아 퀘스트 🎮

0~36개월+ 아기 월령별 돌발 상황을 10개 구간으로 나눈 도트 게임형 육아 가이드. 내 아기 구간 5문항만 풀면 되고, 엄마 성향 테스트·컨디션 체크도 함께 담았습니다.

- 10개 월령 구간(`~30일` · `31~60일` · `61~100일` · `4~6` · `7~9` · `10~12` · `13~18` · `19~24` · `25~30` · `31~36개월+`) × 퀘스트 5문항 = 50문항
- 첫 화면에서 아기 월령을 먼저 고르고, 그 월령 상황으로 엄마 성향 테스트 5문항
- 선택형 `💛 엄마도 같이 챙겨볼까요? (+5문항)` — 엄마 컨디션 체크와 맞춤 회복 팁 3가지
- 결과 엔딩의 `💛 이 시기 엄마 챙기기` 박스 (월령별 돌봄 + 방금 체크한 컨디션)
- 13개월 이후 `🏫 어린이집` / `🏡 가정보육` 분기 체크리스트 (도감에서 토글)
- 육아 도감 · 체크리스트 · 영유아검진 · 추천 아이템 자리
- 모든 화면에서 `🏠 홈`으로 첫 화면(월령 선택) 복귀
- 파일 하나로 동작하는 정적 웹앱 (서버·DB 없음, localStorage `v3`)
