# 육아 퀘스트 🎮

임신 준비부터 36개월+까지, 그 시기에 진짜 터지는 돌발 상황을 15개 구간으로 나눈 도트 게임형 가이드. 내 구간 5문항만 풀면 되고, 엄마 성향 테스트·컨디션 체크도 함께 담았습니다.

- 🤰 **출산 전 · 임신 준비 5개 주수 구간** (`~12주` · `13~19주` · `20~27주` · `28~35주` · `36주~출산`) × 퀘스트 5문항 = 25문항
- 10개 육아 월령 구간 (`~30일` · `31~60일` · `61~100일` · `4~6` · `7~9` · `10~12` · `13~18` · `19~24` · `25~30` · `31~36개월+`) × 퀘스트 5문항 = 50문항
- 첫 화면 맨 앞 `🤰 출산 전 · 임신 준비` 카드 → 주수 5구간 선택 → 성향 테스트
- 구간 상황으로 푸는 엄마 성향 테스트 5문항 (임신은 출산준비물·남편 분담·조리원·검색 습관·지금 챙기는 것)
- 선택형 `💛 엄마도 같이 챙겨볼까요? (+5문항)` — 임신 중엔 허리·손목·붓기·분담·불안 기준으로 체크
- 결과 엔딩의 `💛 이 시기 엄마 챙기기` 박스 (구간별 돌봄 + 방금 체크한 컨디션)
- 13개월 이후 `🏫 어린이집` / `🏡 가정보육` 분기 체크리스트 (도감에서 토글)
- 주수별 태교·놀이 도감 + 산전검사 체크리스트 · 월령별 발달 도감 + 영유아검진 · 추천 아이템 자리
- 모든 화면에서 `🏠 홈`으로 첫 화면(구간 선택) 복귀, 칩으로 주수/월령 전환
- 파일 하나로 동작하는 정적 웹앱 (서버·DB 없음, localStorage `v3`)
